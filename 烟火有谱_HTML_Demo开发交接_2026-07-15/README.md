- `assets/pixel-food/SOURCES.md` 与许可证：必须保留。
- `tools/recipe_data.mjs`：90 道菜的结构化数据源。
- `outputs/019f5b8d-091b-74d0-b08b-64333753978d/中西餐菜品数据库_图片已补全.xlsx`：便于人工核对的数据库。

## 交付原则

- 阶段一必须真的能点、能选、能计算、能保存、能返回。
- 阶段二、三不能伪装成已经完成；入口点击后应展示“功能预览 + 当前状态 + 可用替代操作”。
- AI、小游戏和“非遗”都不能抢走两条主线。
- HTML Demo 采用移动端优先的响应式单页应用，桌面端也可正常演示。
- 不把任何 API 密钥写进 HTML、JavaScript 或仓库。
