# 烟火有谱｜阶段一 HTML Demo 验收清单

## A. 启动与兼容

- [ ] 按 README 的方式可以启动，控制台无阻断性错误。
- [ ] 375px 左右手机宽度可完整操作。
- [ ] 桌面宽度下内容不过度拉伸，底部导航和弹层正常。
- [ ] 刷新后当前核心数据或明确回到可理解的页面。
- [ ] 不依赖真实 AI、登录或微信环境也能完成核心体验。

## B. 第一条主线：根据食材选菜谱

- [ ] 首页首屏能清楚看到“我有这些食材”。
- [ ] 食材可以搜索、分类、添加和删除。
- [ ] 像素食材选中状态清晰，图片不模糊。
- [ ] 点击“用这些食材找菜”能得到本地计算结果。
- [ ] 结果分为“马上能做”“还差 1–2 样”“换个灵感”。
- [ ] 每条推荐都能说明已有食材和缺少食材。
- [ ] 点击推荐可进入正确菜谱详情。

## C. 第二条主线：根据菜谱选食材

- [ ] 首页或菜谱栏目可以搜索和筛选 90 道菜。
- [ ] 菜谱列表使用缩略图并采用懒加载。
- [ ] 菜谱详情显示完整配料，并区分已有与待买。
- [ ] 修改份数时，用量可以同步变化或给出明确的演示说明。
- [ ] 能从菜谱生成采购清单。
- [ ] 重复食材能合并，采购项可以勾选和恢复。
- [ ] 采购清单刷新后仍保留。

## D. 菜谱与烹饪

- [ ] 收藏、最近浏览可在本地保存。
- [ ] 图文教程可逐步前进和返回。
- [ ] 每个烹饪步骤能显示低/中/高火力中的适用档位。
- [ ] 页面退出后能恢复未完成的烹饪进度。
- [ ] 图片加载失败时有回退图或稳定占位，不出现破图布局。

## E. 提醒与边界

- [ ] 使用“过敏原、忌口与特殊人群食用提醒”的统一名称。
- [ ] 提醒可以说明由哪项配料触发。
- [ ] 明确过敏原冲突不会进入“马上能做”。
- [ ] 不出现“AI 已确认安全”等不可靠措辞。
- [ ] 五道地域美食在来源核验前不被无依据地统一标成正式非遗项目。

## F. 阶段二、三预留

- [ ] AI 自然语言录入入口可见，状态标记为下一阶段。
- [ ] AI 照片识别入口可见，不申请权限、不上传照片。
- [ ] AI 替换建议入口可见，点击打开统一预览弹层。
- [ ] 小游戏入口进入视觉预览，而非假装已经可玩。
- [ ] 登录/云同步入口说明当前仅本机保存。
- [ ] 所有预览入口都有可用的阶段一替代操作。
- [ ] 未实现服务统一返回 `FEATURE_NOT_AVAILABLE`。

## G. 性能与工程

- [ ] 首页和列表没有一次性载入 90 张原始 PNG。
- [ ] `assets/dishes/ai/` 只在详情需要时加载对应图片。
- [ ] 没有在浏览器中解析 Excel。
- [ ] 匹配、采购、安全规则和 DOM 渲染没有揉成一个不可维护的大函数。
- [ ] API 密钥、token 和 secret 均未写入前端。
- [ ] 素材来源说明和许可证仍保留在项目中。
