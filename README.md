当前版本：**v1.0.0**  
更新日期：2026-07-18  
当前阶段：阶段一 HTML 核心 Demo 已形成可完整体验的 1.0 版本。阶段二 AI 能力和阶段三小游戏/小程序能力只保留可见入口、功能说明与接口桩，本版本不接入真实服务。

## 一、如何打开

直接双击项目根目录的 `index.html` 即可体验，不需要安装依赖或启动服务器。建议使用最新版 Chrome、Edge 或其他现代浏览器。

报名阶段页面已经归档为 `legacy/registration-demo.html`，不再作为产品入口。

## 二、两条绝对主线

1. **根据食材选菜谱**：选择或输入家中现有食材，系统用本地规则计算“马上能做”“还差 1–2 样”和“换个灵感”。
2. **根据菜谱选食材**：从 90 道菜中选择菜谱，查看已有与缺少配料，并生成可勾选的采购清单。

AI、文化内容、菜品照片和像素素材都服务于这两条主线，不设置独立 AI 或小游戏底部栏目。

## 三、阶段一已经实现

- 首页双主入口与四栏底部导航。
- 35 种像素食材的搜索、分类、选择和手动补充。
- 基于核心食材、覆盖率和饮食设置的本地匹配。
- 90 道菜搜索、分类、时间/难度筛选和收藏。
- 菜谱详情、人数调整、已有/缺少配料和采购清单。
- 采购项目合并、勾选、删除、复制以及加入食材篮。
- “过敏原、忌口与特殊人群食用提醒”的确定性规则。
- 分步骤图文烹饪、低/中/高三档火力、计时器和进度保存。
- localStorage 保存食材篮、收藏、历史、采购清单、设置和烹饪进度。
- 手机优先、桌面兼容的响应式界面。

## 四、只展示、暂未实现

以下功能均有可见入口和统一预览弹层，也保留了接口契约，但不会伪造成功结果：

- 阶段二：AI 自然语言食材录入、食材照片识别、推荐解释、替换食材建议。
- 阶段三：烹饪新手小游戏、微信登录、云同步、微信分享和正式小程序版本。
- 抖音教程：当前只生成并复制搜索词，不抓取或内嵌未经授权的视频。
- 地域技艺故事：当前只展示内容结构，正式资料与非遗名录结论仍需核验。

未来服务接口位于 `src/js/future-services.js`，功能状态位于 `data/features.js`。前端不包含任何 API 密钥。

## 七、数据与安全边界

- 当前 Demo 不发送网络请求，不上传食材、照片或个人设置。
- AI 不能决定过敏原；安全提醒来自明确配料规则，并展示触发原因。
- 特殊人群提醒不替代医生或营养师建议。
- 列表只加载缩略图，不一次性加载约 222 MB 的原始菜品图片。
- 原始数据中的时间、难度、核心食材和过敏原字段属于 Demo 结构化补全，已用 `demoEnriched: true` 标记。
