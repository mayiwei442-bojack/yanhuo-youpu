# Recipe source images

This directory contains authorized copies of images from the single source selected for each published recipe.

Rules:

- Runtime recipe fields reference only local paths under this directory.
- Original image URLs, recipe URL, author, rights notice and SHA-256 remain in `tools/recipe_data.mjs` and the corresponding evidence package.
- A recipe's text, hero and mapped step images must all belong to the same selected source.
- A textual step without a source photo remains text-only; images are never duplicated from another step or borrowed from another source.
- The user confirmed repository-copy authorization for this batch on 2026-09-16.
